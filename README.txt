PS13 PEARL WHITE — custom-build website

FILES
index.html — single-page viewer
styles.css — grey wireframe showroom styling
app.js — Three.js model assembly and rendering
silvia-shell.glb — user's existing Silvia body shell used as the accurate base

BUILD
1992 Nissan Silvia S13 coupe, pearl white, SSR MK2-inspired 15-inch silver-faced polished-lip wheels, generated 195/55R15 tyres, low near-flush stance, Chuki-inspired skirts, Nismo-style rear pods, twin polished left-rear exhaust tips, B-Wave / Pro Shop Wave-inspired wing, Recaro SR3-inspired front seats, and Pignose-inspired front lip adapted to the original Silvia bumper.

IMPORTANT HONESTY NOTE
This is a newly assembled CUSTOM CONFIGURATION using the existing supplied Silvia body shell. It is NOT an entirely scratch-sculpted new body or a photogrammetrically accurate model of the named aftermarket parts. The added parts and SSR MK2-style wheels are custom procedural interpretations; exact real-world measurements, clearances, and product likenesses have not been verified. There are no modification controls yet, per the requested showroom-only design.

INSTALL
Upload index.html, styles.css, app.js and silvia-shell.glb into the ROOT of GitHub repo kuiimo/car-dev. Enable Settings > Pages > Deploy from branch > main > /(root). Visit https://kuiimo.github.io/car-dev/. Hard refresh if you see a cached old version. Three.js loads from esm.sh and requires internet access.
